# 🧰 Dev Setup Script

Este script automatiza a configuração de um ambiente de desenvolvimento em Ubuntu/WSL.

## 🛠 Instala

- Git, Curl, Wget, Zsh
- Python, pip
- Node.js (via NVM)
- Docker
- Aliases úteis

## 🚀 Como usar

```bash
git clone https://github.com/seu-usuario/dev-setup.git
cd dev-setup
chmod +x setup.sh
./setup.sh
